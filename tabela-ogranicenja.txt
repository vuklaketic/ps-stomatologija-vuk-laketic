FAZA 2 - TABELA STRUKTURNIH I VREDNOSNIH OGRANICENJA (tacan tekst)
======================================================================

1. STOMATOLOG
- idStomatolog: integer, NOT NULL AND >0
- ime: String, NOT NULL
- prezime: String, NOT NULL
- email: String, NOT NULL AND LIKE '%@%'
- korisnickoIme: String, NOT NULL
- sifra: String, NOT NULL AND LENGTH(sifra)>8
- brojLicence: String, NOT NULL
Napomena: nema GUI formu za kreiranje (samo login) - proveri da li je ovo relevantno.

2. USLUGA
- idUsluga: integer, NOT NULL AND >0
- naziv: String, NOT NULL
- cena: double, NOT NULL AND >0
- trajanje: integer, NOT NULL AND >=15 AND <=180
Napomena: nema GUI formu za kreiranje - proveri da li je relevantno.

3. ORDINACIJA
- idOrdinacija: integer, NOT NULL AND >0
- naziv: String, NOT NULL
- adresa: String, NOT NULL
Napomena: nema GUI formu za kreiranje - proveri da li je relevantno.

4. SPECIJALIZACIJA
- idSpecijalizacija: integer, NOT NULL AND >0
- naziv: String, NOT NULL
Napomena: IMA GUI formu (NovaSpecijalizacijaDijalog) - proveri da li klijent validira prazan naziv.

5. PACIJENT
- idPacijent: integer, NOT NULL AND >0
- ime: String, NOT NULL
- prezime: String, NOT NULL
- brojTelefona: String, NOT NULL
- brojKnjizice: String, NOT NULL, LENGTH(brojKnjizice)=11
Strukturno: INSERT/UPDATE RESTRICTED Ordinacija (mora imati validnu ordinaciju).

6. TERMIN
- idTermin: integer, NOT NULL AND >0
  Slozeno (medjuzavisnost vise tabela): COUNT(idTermin WHERE idStomatolog=Termin.idStomatolog AND datum=Termin.datum)<=10
  (stomatolog ne moze imati vise od 10 termina istog dana)
- datum: date, NOT NULL
  Slozeno: datum>CURRENT_DATE OR (datum=CURRENT_DATE AND vreme>=CURRENT_TIME)
  (termin ne moze biti zakazan u proslosti)
- vreme: time, NOT NULL
- status: String, NOT NULL
  Slozeno: IF datum<CURRENT_DATE THEN status='Zavrsen' ELSE IF datum=CURRENT_DATE AND vreme<CURRENT_TIME
  THEN status='Zavrsen' ELSE status IN ('Zakazan','U toku','Otkazan')
  NAPOMENA: stvarni StatusTermina enum u kodu ima ZAKAZAN/OTKAZAN/ODRZAN, ne "U toku"/"Zavrsen" -
  ovo je poznato odstupanje izmedju Faze 2 i implementacije, NE MENJATI enum, samo prijaviti.
- napomena: String, NOT NULL

7. STAVKATERMINA
- idTermin: integer, NOT NULL AND >0
- rb: integer, NOT NULL AND >0
- kolicina: integer, NOT NULL AND >0
- cenaUsluge: double, NOT NULL AND >0, cenaUsluge=Usluga.cena (mora se poklapati sa cenom usluge)
- iznos: double, NOT NULL AND >0, iznos=kolicina*cenaUsluge (izracunato polje)

8. STSPEC
- idStomatolog, idSpecijalizacija: integer, NOT NULL AND >0
- datumSticanja: date, NOT NULL
Napomena: nema GUI formu - nije relevantno za sada.
